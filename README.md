Sitio estático listo para editar en Visual Studio Code y subir a un hosting.

## Abrir y previsualizar

1. Descomprime la carpeta y ábrela en Visual Studio Code.
2. Abre `index.html` en tu navegador o usa la extensión Live Server para previsualizarlo.
3. Para publicarlo, sube el contenido completo de esta carpeta a la raíz de tu hosting. Conserva `assets/` junto a `index.html`.

No requiere instalación ni compilación. El sitio usa Google Fonts; si no hay conexión, recurre a fuentes de respaldo.
